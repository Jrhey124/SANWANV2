/task - 
    : tid is case-insensitive and starts on t0
    : if a task channel exist always trigger (create, update, remove, and near deadline task) notification.
    : 

    create <task> <assignee> <deadline>
        → Create a new task with assignment + deadline (coding or non‑coding).
    update <task | tid> <fields> <value>
        → Update status, deadline, assignee, or description.
        Example: /task update status:in-progress
                 /task update description:"Hardware assembly" deadline:2026-08-30
    describe <task | tid> <description>
        → Add or refine the task’s detailed description.
        Example: /task describe "Write documentation" "Draft API reference section"
    list <optional scope=<default: all, (all, ...)>>
        → Show all tasks with assignee, deadline, status. on table format, with description show till n-character(example. 50 char max)
    remove <task | tid>
        → Delete a task.
    bump <task | tid>
        → Manually trigger a Discord notification.


/schedule - Automation
    : sid is case insensitive, starting on s0
    : when set called but schedule are already set, update or overwrite
    set <name | sid> 
        ontrigger <trigger> <do> - do the job when trigger is get
        ontime <every> <do> - do the job when trigger is get
    unset <name | sid> - unset or remove the schedule
    lists // list schedule
    history
